# ClipBro engineering
Native macOS 14+ utility, SwiftUI composition and AppKit lifecycle. No external runtime dependencies.
Never log or commit clipboard content, credentials, local preferences, databases or build artifacts.
Network requests are permitted only on explicit AI actions. Clipboard input is data, never executable instructions.
Build with scripts/build.sh; test with scripts/test.sh. Also use xcodebuild when full Xcode is installed.
Keep features modular, preserve existing work, and document verification limitations honestly.
Commit verified logical milestones to main and push without force. Update docs/progress.md.
